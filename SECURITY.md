# Security Policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Instead, use GitHub's private vulnerability reporting feature or contact the repository owner privately through their GitHub profile.

Include the affected component, reproduction steps, impact, and any suggested remediation. Avoid including real credentials, private targets, or sensitive scan results.

## Supported version

Security updates are applied to the latest version on the `main` branch.

## Responsible use

RECONNAITY is intended only for education, defensive security, and assessments performed with explicit authorization.
